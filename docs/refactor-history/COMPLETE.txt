🎯 THE CORRECT ARCHITECTURE (Clarified!)
════════════════════════════════════════════════════════════════════════════

LOCAL FEATURES (Discord-like, no federation):
  ┌─────────────────┐
  │   Server Chat   │ → Supabase only
  │ Voice Channels  │ → WebRTC P2P
  │ Local DMs       │ → Supabase only
  └─────────────────┘

FEDERATED FEATURES (Cross-instance):
  ┌─────────────────┐
  │ Public Posts    │ → Supabase → Federation Backend → Fediverse
  │ Remote DMs      │ → Supabase → Federation Backend → Remote User
  │ Follows         │ → Supabase → Federation Backend → Remote Instance
  │ Reactions       │ → Supabase → Federation Backend → Remote Post
  └─────────────────┘

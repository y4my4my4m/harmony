# Keyboard shortcuts

This page lists every key the Harmony app responds to, grouped by where it works. For how keyboard and screen reader use fits together, see [Accessibility](/use/accessibility).

## Modifier keys

| Written here | Windows and Linux | Mac |
|---|---|---|
| Ctrl/Cmd | Ctrl | Cmd or Control; both work |
| Ctrl | Ctrl | Control |
| Alt | Alt | Option |

Voice shortcuts match their keys exactly as recorded. **User settings** → **Keybindings** names the modifiers Ctrl, Alt, Shift and Meta; Meta is Cmd on a Mac and the Windows key on Windows. A voice shortcut recorded with Ctrl needs the Control key on a Mac.

## Everywhere

| Keys | Action |
|---|---|
| Tab | The first Tab stop on a page is **Skip to content**; Enter on it moves focus to the main content. |
| F6 / Shift+F6 | Move focus to the next or previous region: servers, channels, messages, members, voice connection, your account panel. Not while a dialog is open. |
| Ctrl+F6 / Ctrl+Shift+F6 | The same, for browsers that keep F6 for the address bar. |
| Escape | Close the topmost dialog, menu or drawer. Focus returns to where it was. |
| Escape | Close **User settings** or **Server settings** when no dialog or menu is open over it. |
| Ctrl/Cmd+K | Open **Search messages** for the current server or direct message conversation. Works in chat, not on the social side. |

In a web browser and in the installed web app (PWA), but not in the desktop or Android app:

| Keys | Action |
|---|---|
| Ctrl/Cmd+R | Reload the app. |
| Ctrl/Cmd+Shift+R | Delete the app's cached files, then reload. |
| F11 | Enter or leave full screen. |

## Voice and video

These shortcuts are listed in **User settings** → **Keybindings**, where each one can be turned off, recorded anew or reset.

| Shortcut | Default | Works |
|---|---|---|
| **Push to talk** | V, held | While connected to voice, when the input mode is **Push to talk**. |
| **Toggle mute** | Ctrl+Shift+M | While connected to voice. |
| **Toggle deafen** | Ctrl+Shift+D | While connected to voice. |
| **Toggle camera** | V | While the call view is open. |
| **Toggle screen share** | S | While the call view is open. |
| **Open voice settings** | `,` | While the call view is open. |
| **Exit / close** | Escape | With focus inside the call view. |

- In a text field, only push to talk and shortcuts that include Ctrl, Alt or Meta fire. Push to talk transmits and the letter is typed as well.
- When push to talk and **Toggle camera** share a key, push to talk wins.
- **Exit / close** acts in this order: closes an open popover, leaves full screen, leaves the full-window view, leaves focus view, closes voice settings, then minimizes the call view.
- In the desktop app push to talk also works while Harmony is in the background, where the system allows it. In a browser it works only while the Harmony tab has focus. See [Use push to talk](/use/voice-video#use-push-to-talk).

### Change a voice shortcut

1. Open **User settings** → **Keybindings**.
2. Focus the shortcut's key button and press Enter or Space, or click it, to start recording.
3. Press the new keys. Escape cancels. Enter, Space and the arrow keys need a modifier such as Ctrl. An extra mouse button (such as Mouse 4 or Mouse 5), or any mouse button with a modifier held, can be recorded too.
4. If the keys are taken by another shortcut, Harmony says so and does not assign them; **Assign anyway** assigns them regardless.

The reset button beside each shortcut restores its default, and **Reset all** restores every default. When **Toggle mute** or **Toggle deafen** sits on a single key, the page offers a button that moves them to Ctrl+Shift+M and Ctrl+Shift+D. Keybindings are stored per device.

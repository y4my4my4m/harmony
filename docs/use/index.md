# Use Harmony

This section is for people who chat on a Harmony instance. Server owners should read [Run a server](/run/); people running their own instance should read [Self-host](/self-host/).

Harmony is a chat app you reach through an instance: a Harmony deployment at its own domain, such as the flagship instance https://har.mony.lol. On it you join servers, which are communities organised into text and voice channels. Text channels carry messages, replies, threads, polls and reactions; voice channels carry voice, video and screen sharing. Direct messages and group chats work outside any server, with their own calls. The **Fediverse** button opens a social timeline of posts, and **Drive** holds every file you send. Instances federate over ActivityPub, so you can join a server hosted on another Harmony instance and mention people on other instances without a second account.

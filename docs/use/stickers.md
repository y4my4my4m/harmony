# Stickers

This page covers custom stickers: the ones a server, your instance or you uploaded. Stickers from KLIPY are covered in [Messages and threads](/use/messages#attach-files-gifs-and-stickers).

## Send a sticker

1. Open the **GIF picker** in the composer and choose the **Stickers** tab.
2. Custom stickers are listed above KLIPY's, in up to three groups: the current server's stickers (under the server's name), **Instance stickers** and **My stickers**. A server's stickers are offered only in its own channels and threads; a direct message offers instance and personal stickers.
3. Type in the search field to narrow the list by a sticker's name or description.
4. Select a sticker. It is sent at once.

In a channel or a direct message, text already typed in the composer goes in the same message, above the sticker, and the reply you were writing stays a reply. In a thread, the sticker is sent on its own. A message holds one sticker.

A sticker shows at up to 160 pixels. Screen readers read it as "Sticker", its name and its description. Editing a message changes its text and keeps the sticker.

## Personal stickers

Personal stickers are yours alone: you can send them in any server or conversation, and nobody else can. Manage them in **User settings** → **My stickers**.

Personal stickers are off unless your instance allows them. While they are off, the page says so and shows no upload form. Once an admin sets a limit, the count beside the list shows yours against it.

To add one, choose an **Image**, check the **Name** (filled in from the file name), write a **Description**, and select **Upload sticker**. **Edit** changes the name and description; **Delete** removes the sticker.

## Limits

| | Limit |
|---|---|
| File type | PNG, APNG, WebP or GIF. JPEG, SVG and video are refused. |
| File size | 512 KB |
| Size | 320 × 320 pixels. A larger still image is scaled down before upload; an animated one is refused. |
| Animation | 5 seconds per loop. Frames of 10 ms or less count as 100 ms, as browsers play them. |
| Name | 2 to 30 characters, unique among the stickers of the same server, of the instance, or of yours |
| Description | Required, up to 300 characters |
| Stickers per message | 1 |

The instance sets how many stickers each server, the instance and each person can keep: by default 15 per server, 50 for the instance and no personal stickers.

## Removed stickers

When a sticker is removed (by whoever uploaded it, a member who manages the server's stickers, or the instance's staff), messages that sent it show **Sticker removed** in its place. A sticker from another instance whose image no longer loads shows **Sticker unavailable**.

## Report a sticker

Right-click a message with a sticker of your instance (or press and hold it on a touch screen) and select **Report sticker**. The report goes to your instance's admins and moderators, who can remove the sticker for everyone. You cannot report your own personal sticker. To report a sticker from another instance, report the message.

## Stickers on other instances and apps

A sticker travels with an image copy of itself, described by the sticker's description:

- Harmony instances on 1.9.2 or later show it as a sticker.
- Older Harmony apps and instances, Mastodon and other ActivityPub software show the image, with the description as its alt text.
